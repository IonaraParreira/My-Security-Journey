## 🚀 Por que Segurança na Nuvem?
Com a evolução do mercado, o perímetro de segurança mudou do espaço físico para a **identidade** e a **configuração lógica**. O conhecimento em redes e protocolos (HTTP, TCP/IP, DNS) é a base para proteger a infraestrutura moderna.

## 🛠️ Próximos Passos Práticos

### 1. Modelo de Responsabilidade Compartilhada
* **Provedor (ex: AWS):** Responsável pela segurança *da* nuvem (infraestrutura física).
* **Cliente (Eu):** Responsável pela segurança *na* nuvem (configurações, dados e código Back-end).

### 2. Laboratório de Redes na Nuvem (VPC)
Arquitetura de rede segura a ser replicada na prática:
- [ ] Criar uma **VPC** (Virtual Private Cloud) isolada.
- [ ] Configurar **Sub-redes Públicas** (para APIs/Servidores Web).
- [ ] Configurar **Sub-redes Privadas** (para Bancos de Dados, isolados da internet).
- [ ] Aplicar regras estritas de **Firewall / Security Groups** (bloqueando portas desnecessárias e permitindo apenas tráfego legítimo).

### 3. Foco em Application Security (AppSec)
* Implementar e estudar o funcionamento de um **WAF (Web Application Firewall)** para proteção contra ataques na camada web (SQL Injection, XSS).
