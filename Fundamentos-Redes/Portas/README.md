<h2>Portas de Escuta👂🏻(Listen)</h2>
São portas que ficam abertas no servidor esperando conexões externas(como a porta 443 do GitHub).Essa precisa de atenão e segurança.

<h2>Portas Efêmeras(Saída)</h2>
Tendo como exemplo port privada 52775
Foi uma porta temporária que o Windowns abriu apenas para enviar o pedido e receber a resposta do GitHub.Significa que assim que o comando curl terminnou e o JSON foi exibido na tela, essa porta foi fechada automaticamente pelo sistema operacional.Não existe mais.
